# 🎬 Netflix Data Analysis Project

This project performs Exploratory Data Analysis (EDA) on the Netflix dataset to uncover insights about movies, TV shows, genres, ratings, content growth, and duration trends using Python data analysis libraries.


## 🛠 Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Analysis
- Movies vs TV Shows
- Top Producing Countries
- Year-wise Content Growth
- Genre Analysis
- Rating Distribution
- Average Movie Duration
- Business Insights
